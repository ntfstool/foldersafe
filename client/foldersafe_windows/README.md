# FolderSafe for Windows (planned, not started)

A native Windows client is planned. It will:

- implement [vault format v1](../../docs/spec/vault-format-v1.md) natively (compatible with Cryptomator vault format 8),
  pass the public test vectors, and read and write vaults created by the macOS / iPhone apps and by Cryptomator;
- present an unlocked vault as a folder;
- keep device keys (Windows Hello) on the device only, never in the vault.

Nothing here yet. Discussion and help are welcome in the issue tracker.
